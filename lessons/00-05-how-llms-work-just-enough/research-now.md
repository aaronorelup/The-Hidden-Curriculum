## 1. From text-only LLMs to multimodal models (and who generates what)

## 2. Tokens, the context window, and context rot

- The context window holds everything: system prompt, every message, tool definitions, tool results, images, documents, and the model's own output including thinking. https://platform.claude.com/docs/en/build-with-claude/context-windows (live doc) **[established]**
- Anthropic's own docs now name the problem: "As token count grows, accuracy and recall degrade, a phenomenon known as *context rot*." Curating context is "just as important as how much space is available". Same page (live doc) **[established]** (term popularised 2025)
- Chroma's July 2025 "Context Rot" study: 18 frontier models all degraded as input grew, even on trivial retrieval tasks, well before the window was full. https://particula.tech/blog/chroma-context-rot-long-context-degradation (2025-26 summary); https://www.morphllm.com/context-rot **[established]**
- 1M tokens is now the default (no beta header, standard price) on all current Claude models except Haiku; "1M tokens is roughly 555k words" on the new tokenizer. https://platform.claude.com/docs/en/about-claude/models/overview; https://platform.claude.com/docs/en/about-claude/pricing (live docs) **[new]**
- New tokenizer (Claude 4.7 and later) produces ~30% more tokens for the same text: token counts are not comparable across model generations. https://platform.claude.com/docs/en/about-claude/pricing (live doc) **[new]**
- Rule of thumb still in docs: 1 token ≈ 4 characters ≈ 0.75 English words (older tokenizer). Same page **[established]**
- Countermeasures shipped by vendors: server-side **compaction** (summarises older turns; beta, Claude 4.6+), **context editing** (clears old tool results/thinking), **tool search** (tool definitions deferred until needed), subagents (verbose work in a separate window). Claude Code auto-compacts near the limit. https://platform.claude.com/docs/en/build-with-claude/context-windows (live doc); https://code.claude.com/docs/en/costs (live doc) **[new]** / compaction **[beta]**
- OpenAI's Agents API (public beta 2026-09-10) also manages "context compaction". https://developers.openai.com/api/docs/changelog **[beta]**
- Some Claude models (Sonnet 5, 4.6, 4.5, Haiku 4.5) get injected "token budget" updates ("context awareness"); newer Opus/Fable/Sonnet 5.5 use opt-in task budgets (beta) instead. https://platform.claude.com/docs/en/build-with-claude/context-windows (live doc) **[new]**

## 3. Memory and RAG: the ways a model "remembers"

Core idea to keep: the model itself remembers nothing between requests; every "memory" is text that something puts back into the context window.

- **Chat search** (Claude "Search and reference chats"): Claude searches past conversations via a tool. Paid plans (Pro, Max, Team, Enterprise). https://support.anthropic.com/en/articles/11817273-how-does-claude-s-memory-work (live help) **[established]**
- **Self-kept memory** (Claude "Generate memory from chat history"): Claude builds a summarised profile from chat history, updated roughly every 24 h, viewable/editable. Launched Aug 2025 for paid plans; free plan got memory in March 2026, plus an **import tool** to bring memory from ChatGPT/Gemini. https://9to5mac.com/2026/03/02/free-claude-users-can-now-use-memory-and-import-context-from-rivals/ (2026-03-02) **[new]**
- ChatGPT: "saved memories" + "reference chat history"; "Dreaming V3" (rolling out from 2026-06-04) synthesises memory in the background and rewrites old memories. https://www.digitalapplied.com/blog/chatgpt-memory-dreaming-v3-openai-2026-guide (2026); https://www.xda-developers.com/chatgpt-quietly-rewrites-its-memories-of-you-not-sure-i-like-it/ (2026) **[new]**
- Gemini: "Past Chats" memory under Personal Intelligence, rolled out to free users Feb-Mar 2026 (not in EEA/UK/CH). https://9to5google.com/2026/02/26/gemini-past-chats-free/ (2026-02-26) **[new]**
- **Agent writes its own files**: Claude Code "auto memory" (notes Claude writes itself, per repository; first 200 lines/25KB loaded every session). https://code.claude.com/docs/en/memory (live doc) **[new]**
- **API memory tool**: Claude reads/writes files under `/memories` via tool calls; the app stores them (files, DB). "Memory lives entirely in your application." https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool (live doc) **[established]** (tool shipped 2025)
- **External stores via tools/connectors**: Notion, Google Drive, a folder of markdown files: the model only sees them when it calls a tool (MCP connector, file read). Costs a tool call and context space each time. **[established]**
- **RAG** (retrieval-augmented generation): fetch relevant chunks, paste them into the context, then answer. Claude Projects switch to RAG mode automatically when project knowledge nears the context limit ("up to 10x" capacity; paid plans). https://support.claude.com/en/articles/11473015-retrieval-augmented-generation-rag-for-projects (live help) **[established]**
- Trend: coding agents moved from vector-database RAG to **agentic search** (grep/glob/read, the agent decides what to look at); Claude Code dropped its early vector index for this. Vector RAG still wins for large unstructured prose. https://smartscope.blog/en/ai-development/practices/rag-debate-agentic-search-code-exploration/ (2026); https://dev.to/nimay_04/rag-is-not-always-the-answer-anymore-how-ai-agents-search-code-in-2026-43m3 (2026) **[new]** (trend)
- Personal agents push memory furthest: Hermes Agent advertises a 4-layer memory (session history, user profile, full-text search, procedural "skills"). https://www.truefoundry.com/blog/openclaw-vs-hermes (2026) **[new]**
- Deeper lesson owners: 06.06 vector databases & RAG.

- **CLAUDE.md** (Claude Code): plain markdown files loaded into context at session start. Load order broadest to narrowest: managed policy (IT-deployed, can't be excluded) → user `~/.claude/CLAUDE.md` → project `./CLAUDE.md` or `./.claude/CLAUDE.md` → `CLAUDE.local.md`. ## 5. Diffusion models (and the rare diffusion LLM)

- One picture: start from pure noise, a network removes a little noise per step, guided by the prompt, until an image (or audio/video) emerges. Modern models do this in a compressed "latent" space and decode at the end. https://iclr-blogposts.github.io/2026/blog/2026/diffusion-architecture-evolution/ (2026) **[established]**
- Most current image models (Stable Diffusion 3, Flux) technically use **flow matching / rectified flow**, a close cousin of diffusion that predicts a straight-line "velocity" from noise to image and needs fewer steps. Still noise-to-image; fine to call it the diffusion family. https://www.datacamp.com/tutorial/what-is-flow-matching; https://www.paiteq.com/blog/diffusion-vs-flow-models/ (2026) **[established]**
- Audio: Stable Audio 3 (2026) is a latent diffusion transformer trained with flow matching; sound-effect generators (Stable Audio Open, AudioLDM 2, TangoFlux) are diffusion/flow based. https://arxiv.org/html/2605.17991 (2026-05) **[new]**
- Video: current video generators (Veo, Kling, Seedance, Wan, MiniMax/Hailuo) are diffusion-transformer family models; architecture details for closed models are not all published. Aaron's own local tools (MiniMax-H3, Qwen-Image) are this family. **[established]** (closed-model internals: hedge)
- Not every image generator is diffusion: OpenAI's GPT Image line is widely reported as **autoregressive** (generates image tokens like text), replacing diffusion-based DALL-E 3 (support ended May 2026). OpenAI has not fully published the architecture. https://en.wikipedia.org/wiki/GPT_Image; https://ai-tldr.dev/learn/multimodal-ai/image-generation/diffusion-vs-autoregressive/ **[new]** (architecture: hedge "reported")
- **Diffusion LLMs** (text from noise, many tokens refined in parallel):
  - Inception **Mercury 2.5**, released 2026-09-08: ~1,107 tokens/s, 260K context; quality comparable to small/cheap models (Haiku 4.5, GPT-5.6 Luna class), not frontier. https://www.inceptionlabs.ai/blog/introducing-mercury-2-5 (2026-09-08); https://gigazine.net/gsc_news/en/20260909-mercury-2-5/ (2026-09-09) **[new]**
  - Google **DiffusionGemma** (open weights, Apache 2.0, 26B MoE / 3.8B active), released 2026-06-10: denoises 256-token blocks in parallel, up to ~4x faster than Gemma, lower quality; positioned as experimental. https://siliconangle.com/2026/06/10/google-open-sources-speedy-diffusiongemma-text-diffusion-model/ (2026-06-10); https://the-decoder.com/googles-new-open-model-diffusiongemma-generates-text-from-noise-instead-of-word-by-word/ **[new]**
  - **Gemini Diffusion** (shown May 2025) remains an experimental research preview with no public pricing as of Sep 2026. https://tech-insider.org/mercury-2-5-vs-gemini-diffusion-llm-speed-2026/ (2026-09) **[beta]**
  - Safe line for narration: diffusion text models exist and are very fast, but every frontier chat model is still autoregressive (next-token). **[established]**

## 6. Model settings ("sampling parameters") - brief

- Classic knobs: **temperature** (randomness), **top-p** (sample only from the smallest set of tokens whose probabilities sum to p), **top-k** (only the k likeliest tokens), **max output tokens** (hard cap on the reply). **[established]**
- BIG CHANGE: Anthropic removed temperature/top-p/top-k as controls starting with Claude Opus 4.7. On Opus 4.7 and later (incl. Opus 5.5) any non-default value returns a 400 error; the Python SDK v1.0+ no longer defines them. Docs: "If you were using `temperature = 0` for determinism, note that it never guaranteed identical outputs." https://platform.claude.com/docs/en/models/opus-5-5/migration-guide (live doc) **[new]**
- Replacement knob: **effort** (`low`, `medium`, `high`, `xhigh`, `max`) controls how many tokens the model spends on thinking, tool calls and text. Opus 5.5 defaults to `medium`; most others `high`. https://platform.claude.com/docs/en/build-with-claude/effort (live doc) **[new]**
- **Adaptive thinking** (model decides how much to think) is always on and cannot be disabled on Opus 5.5 and Fable; manual "extended thinking" budgets are deprecated/not accepted on newest models. Thinking tokens are billed as output and count against max_tokens. https://platform.claude.com/docs/en/about-claude/models/overview; https://platform.claude.com/docs/en/build-with-claude/context-windows (live docs) **[new]**
- Max output: 128K tokens on current Claude models (300K via Batch beta). https://platform.claude.com/docs/en/about-claude/models/overview (live doc) **[new]**
- Other "settings" learners now meet: **fast mode** (research preview; Opus 5.5 at $8/$40 for faster output), **model choice**, **effort** picker in apps and `/effort` in Claude Code. https://platform.claude.com/docs/en/about-claude/pricing (live doc) **[beta]**
- OpenAI: GPT-Image 2.5 adds `xhigh`/`max` quality settings; OpenAI "Fast mode" replaced Priority Processing (2026-07-30). https://developers.openai.com/api/docs/changelog **[new]**
- Lesson framing: on chat apps the user never set temperature anyway; what users actually touch in 2026 is model, effort/thinking, and speed.

## 7. Prompt caching and the four kinds of tokens

Mechanism: the provider stores the model's computed internal state (the KV cache) for a prompt *prefix*; a later request that starts with the exact same prefix skips recomputing it. vLLM docs: it stores "the KV cache of existing queries" so new queries can "skip the computation of the shared part". https://docs.vllm.ai/en/latest/features/automatic_prefix_caching.html (live doc) **[established]**

- Prefix order is tools → system → messages; a change at any level invalidates that level and everything after it. Requires a 100% identical prefix. https://platform.claude.com/docs/en/build-with-claude/prompt-caching (live doc) **[established]**
- What breaks the cache (Anthropic): changing tool definitions (breaks all), toggling web search/citations, speed setting, thinking parameters, tool_choice, adding/removing images, any edit before the breakpoint; changing top-level effort mid-conversation (per-message effort beta preserves it); switching model. Same page + https://platform.claude.com/docs/en/build-with-claude/effort (live docs) **[established]**
- Lifetime (TTL): default **5 minutes**, optional **1 hour**; each cache hit refreshes the timer for free; the clock starts at the beginning of the request. Same page **[established]** (1h option since 2025)
- Claude Code: cache lifetime is **1 hour on a subscription**, **5 minutes** on an API key/cloud provider or once you are drawing on usage credits. "Your first message after a break longer than the cache lifetime misses the cache and reprocesses your full context." Compaction and `/compact` also force a rebuild. `/usage` now shows cache hit %, misses and warm/cold state. https://code.claude.com/docs/en/costs (live doc) **[new]**
- Four token lines on a bill (`usage` fields): `input_tokens` (fresh input after the last cache point, full price), `cache_creation_input_tokens` (cache **write**: 1.25x input for 5-min TTL, 2x for 1-hour), `cache_read_input_tokens` (cache **read**: 0.1x input on most models; 0.05x on Opus 5.5; 0.025x on Fable/Mythos 5.1), `output_tokens` (everything generated incl. thinking; ~5x input price). All cached tokens still occupy the context window. https://platform.claude.com/docs/en/about-claude/pricing; https://platform.claude.com/docs/en/build-with-claude/prompt-caching (live docs) **[established]** (new read multipliers **[new]**)
- Concrete prices per million tokens (Claude API): Opus 5.5 input $4, 5-min write $5, 1-h write $8, read $0.20, output $20. Sonnet 5.5: $2 / $2.50 / $4 / $0.20 / $10. Haiku 4.5: $1 / $1.25 / $2 / $0.10 / $5. Fable 5.1: $10 / $12.50 / $20 / $0.25 / $50. Same pricing page **[new]**
- Break-even: a 5-min cache pays off after one read; a 1-hour cache after two reads. Same page **[established]**
- Minimum cacheable prefix: 512 tokens on newest models (up to 4,096 on some older ones); shorter prompts silently aren't cached. Prompt caching page **[new]**
- **Automatic caching** (one top-level `cache_control`; breakpoint moves forward as the conversation grows) is now the recommended default; up to 4 explicit breakpoints; "pre-warming" with `max_tokens: 0`; cache diagnostics API. Same page **[new]**
- OpenAI: caching is automatic for prompts over 1,024 tokens, cached input up to 90% off; extended retention up to 24 h on GPT-5.5-era models; for GPT-6, discounts apply to shared prefixes reused within a 30-minute window, plus explicit breakpoints, prewarming and a cache dashboard; effort changes no longer break cache. https://dev.to/rikuq/openai-prompt-caching-explained-automatic-free-to-enable-90-off-cached-input-tokens-7bn (2026); https://x.com/OpenAIDevs/status/2102506476401258678 (2026-09); https://xnews.sk/en/2026/09/23/openai-improves-prompt-caching-gpt-6-diagnostics-breakpoints/ (2026-09-23) **[new]**
- Google: implicit caching on by default for Gemini 2.5+ (~90% discount); "Durable Caching" GA on Google Cloud announced for 2026-10-15. https://github.com/uriva/ai-utils/issues/4 (2026, secondary) **[beta]** (hedge)
- Other bill modifiers: Batch API 50% off; US-only inference 1.1x; long context billed at standard rate (no surcharge) on Claude 4.6+. https://platform.claude.com/docs/en/about-claude/pricing (live doc) **[new]**
- Why a long chat gets expensive even on a subscription: the whole conversation is re-sent on every turn (cheaply, as cache reads, if warm). https://code.claude.com/docs/en/costs **[established]**
- Deeper owner: 10.11 subscriptions vs API billing.

## 9. Skills vs connectors vs plugins, and where you get them

- **Skill** = a folder with a `SKILL.md` (name + description + instructions, optional scripts/files). Only the name/description sit in context until the task needs it ("progressive disclosure"). Launched 2025-10-16; released as an **open standard** (agentskills.io) 2025-12-18; adopted by Codex, Gemini CLI/Antigravity, Copilot, Cursor, JetBrains and 30+ tools. https://siliconangle.com/2025/10/16/anthropics-skills-claude-helps-ai-agents-perform-certain-tasks-better/ (2025-10-16); https://www.firecrawl.dev/blog/agent-skills (2026); https://developers.openai.com/codex/skills (live doc) **[new]**
- **Connector** = a link to an outside service (Gmail, Drive, Notion, Slack...), built on **MCP**; gives Claude tools + data. Claude Code defers MCP tool definitions by default (tool search) to save context. https://code.claude.com/docs/en/costs (live doc) **[established]**
- **Plugin** = an installable bundle of skills + connectors (MCP servers) + slash commands + subagents + hooks for one job. In Claude Code, plugins come from **marketplaces** (a git repo with `.claude-plugin/marketplace.json`; official one `claude-plugins-official`; anyone can host one; orgs can require one). https://code.claude.com/docs/en/plugin-marketplaces (live doc) **[new]**
- One-liner used widely: "Connectors bring your data in, plugins give Claude capabilities, skills give Claude your methodology." https://beginnersinai.org/claude-skills-connectors-plugins/ (2026) **[established]**
- Where to get them (Anthropic): unified **Directory** at claude.ai/directory (skills, connectors, plugins together since 2026-03-31, per secondary source); **Claude Marketplace** launched **2026-09-23** with 2,000+ connectors and plugins plus "Agents & Products" (CrowdStrike, Cursor, Harvey, Lovable, Snowflake...) and "Service Partners"; enterprises can pay with committed Anthropic spend; developer submission portal live 2026-09-25. https://www.ghacks.net/2026/09/27/anthropic-launches-claude-marketplace-with-more-than-2000-connectors-and-plugins/ (2026-09-27); https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-turns-claude-into-an-ai-marketplace-with-2-000-plus-plugins-and-connectors/ (2026-09) **[new]**
- OpenAI equivalents: "connectors" renamed **apps** (Dec 2025, Apps SDK on MCP); since 2026-07-09 ChatGPT has **plugins** again (bundles of apps + skills + templates, replacing the app directory); Codex skills catalog on GitHub. https://www.gradually.ai/en/chatgpt-plugins/ (2026); https://github.com/openai/skills **[new]**
- Third-party skill/plugin directories exist (claudemarketplaces.com, skills directories, OpenClaw's ClawHub). Third-party = unvetted: ClawHub had 341+ malicious skills found in Feb 2026 (see §13). https://thehackernews.com/2026/02/researchers-find-341-malicious-clawhub.html (2026-02) **[new]**

- Still present in every model. ## 15. Where it is heading (dated signals only)

- Fewer modes, one agent: Anthropic (2026-09-16) and OpenAI (2026-07-09) both collapsed chat + agent work into one app; Claude Code / Codex remain the developer mode. **[new]**
- Always-on agents on their own cloud machines (dots, Muse, one Claude after the laptop closes). **[new]**
- Bigger windows are no longer the race; curation is (compaction, memory files, skills loaded on demand, tool search). **[new]**
- Knobs move from sampling (temperature) to effort/thinking. **[new]**
- Open standards for the plumbing: MCP, AGENTS.md, Agent Skills under/alongside the Linux Foundation's Agentic AI Foundation. **[new]**
- Diffusion text models: fast, open (DiffusionGemma) and commercial (Mercury 2.5), but not frontier quality; whether they reach frontier is open. **[speculation]**
- Enterprise procurement through marketplaces (Claude Marketplace, committed-spend purchases). **[new]**

## Traps (things commonly said that are now wrong)

1. "Just set temperature to 0 for consistent answers." Newest Claude models reject non-default temperature/top-p/top-k (400 error) since Opus 4.7; effort and adaptive thinking replaced them; and temperature 0 never guaranteed identical output.
2. "Claude has a 200K context window." Current Claude models (except Haiku 4.5) have 1M by default at standard price.
3. "A bigger context window means it remembers everything you put in." Accuracy degrades as context fills (context rot), well before the limit.
4. "The model remembers you." The model is stateless; memory is text (summaries, files, search results) put back into the context by the app.
5. "Memory is a paid feature." Claude memory has been on the free plan since March 2026; Gemini Past Chats rolled out to free users too.
6. "RAG means a vector database." Coding agents mostly use agentic search (grep/read); Claude Projects switch to RAG automatically.
7. "CLAUDE.md is a config file Claude must obey." It is context, not enforcement; hooks/permissions enforce. And Claude Code now also reads AGENTS.md.
8. "Cowork is a separate mode you switch to." Merged into Claude chat on 2026-09-16 (rolling out); Claude decides when a request needs work.
9. "Claude has three modes: Chat, Cowork, Code." Now effectively two: Claude and Claude Code.
10. "Claude can't run while your computer is off." Cloud sessions, Routines and the merged Claude keep working after the laptop closes.
11. "ChatGPT generates videos with Sora." Sora was shut down in spring 2026.
12. "All image generators are diffusion models." GPT Image is reported to be autoregressive; most others are diffusion/flow matching.
13. "Diffusion is only for images." It is used for video, audio/music and (rarely) text (Mercury 2.5, DiffusionGemma).
14. "Multimodal means one model does everything." Mostly the app routes to separate specialist models (ChatGPT + GPT Image + GPT-Live; Gemini + Nano Banana + Veo + Lyria). Claude still outputs only text.
15. "Cached tokens are free / don't count." Cache reads cost 2.5-10% of input price and still fill the context window; cache writes cost more than normal input (1.25x or 2x).
16. "The cache lasts for the whole conversation." It expires after 5 minutes (or 1 hour) of inactivity, and any change earlier in the prompt (tools, system prompt, model, images, top-level effort) forces a rebuild.
17. "Your $20 subscription can power any agent." Since 2026-04-04 Claude subscriptions can't be used in third-party harnesses like OpenClaw; those need API keys.
18. "Paid plans are never used for training." Consumer plans (incl. Pro and Max) are used for training unless you opt out (since Sept 2025); Team/Enterprise/API are not by default.
19. "Gemini CLI" as Google's coding agent: retired 2026-06-18, replaced by Antigravity.
20. "Voice mode is Haiku-only / can't use tools." Claude voice can use Opus/Sonnet and connected apps since 2026-07-23; ChatGPT voice is now full-duplex GPT-Live.
21. "Hermes Agent is OpenClaw's successor." It is an independent competitor from Nous Research.
22. "Token counts are comparable across models." Claude 4.7+ tokenizer yields ~30% more tokens for the same text.
23. Old prices ("Opus costs $15/$75", "Sonnet $3/$15") are from 2024-25; current Opus 5.5 is $4/$20, Sonnet 5.5 $2/$10.
