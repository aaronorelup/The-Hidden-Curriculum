## 01 — The point
[[point-purpose]]In this lesson you'll learn about the hidden layer of files on your computer, what lives in it, and why you need to know it is there. [[point-conclusion]]Almost every project and app keeps its settings, its history, its secrets, and now its AI instructions in files your computer hides. Hidden only means out of sight. It never means locked. [[point-secrets]]Your secret keys live in that layer. [[point-agents]]AI agents read and write it, so it's the first place to look when something changed that you didn't see.

## 03 — The mental model

## 04 — Why it's hidden: two kinds of sign
[[painted-dot]]There are two kinds of sign. On Mac and Linux, the sign is painted into the name: a name that starts with a dot is skipped when a folder is listed. [[pike]]As Rob Pike, one of the early Unix programmers, tells it, this began as a shortcut in the list command, meant to hide two special entries, dot and dot dot. It hid every name that starts with a dot, and people started putting settings there. Pike later called it a mistake. [[flag-on-door]]Windows ignores the dot. There, hiding is a flag hung on the file itself, called the Hidden attribute. [[open-doors]]So on Windows, a dotted name sits in plain view unless something hung the flag. Git for Windows flags its own dot git folder. [[show-hidden]]Every system can show hidden items.
> Hedged per plan section 8: Pike's recollection, no year, no name for who wrote the shortcut. show-hidden is screen labels only, not steps: "View > Show > Hidden items", "Cmd+Shift+.", "ls -a", "Get-ChildItem -Force".

## 05 — Two back rooms: the project's and yours
[[project-room]]There's more than one back room. Each project has its own: the dot folders and dot files inside the project folder. They travel with the project. [[house-room]]And you have one at home, in your home folder, for settings that belong to you. [[dot-config]]On Linux, the tidy answer is a dot config folder, and many tools use it on a Mac too. Plenty of tools ignore it and leave their own dot folder at the top instead, like dot S S H or dot Claude. [[appdata]]On Windows, the home back room is App Data, hidden on a normal install, with three rooms. Roaming is meant to follow a work login from machine to machine. Local stays on this machine. Local Low is for programs running with fewer permissions; today it's mostly games.
> Optional screen label only (not spoken): "46 dot-named items · one Windows home folder · 2026-10-09" (direct observation on the course machine; do not generalise). Roaming wording is for work/domain logins, not a home PC.

## 06 — What's on the project's shelves
[[dot-git]]Now the project's shelves. The big one is the logbook: a folder called dot git, holding every past version of your project. Delete that one folder and your files stay. Their history is gone. [[toolbox]]Next to it sits a private toolbox: dot V E N V. It holds a pointer to your Python and the project's own packages. Aaron, who made this course, had an IT degree and still didn't know what dot V E N V was. [[self-ignore]]Since Python 3.13, and in the tool U V, a new dot V E N V tells git to ignore itself. [[gitignore]]Taped to the wall is a list: dot git ignore. It names what never goes on the moving van. It hides nothing. It only tells git what not to pack. [[editor-settings]]Editor settings live here too, like dot V S Code.
> Python 3.13 = October 2024. Older Python and other tools do not self-ignore.

## 07 — The drawer of keys with no lock
[[env-file]]Now the drawer that matters most. At the root of many projects sits a file called dot E N V. Inside are plain lines: a name, an equals sign, and a value, usually a key or a password. When your program starts, if it's set up to look for this file, it loads those lines as environment variables. [[no-lock]]That drawer has no lock. It's plain text. Hidden means out of sight, not encrypted. [[never-commit]]Rule one: it never goes into git. Put it on the git ignore list before your first commit. Adding it later doesn't pull it out of the history, and once a key has leaked, the only real fix is to replace it. [[never-paste]]Rule two: never paste it into a chat, and never let an agent read it. Claude Code's own documentation says that anything a tool reads, a key included, ends up in a transcript file in another hidden folder. [[push-net]]GitHub now blocks some known kinds of key from reaching public repositories, but only the kinds it recognises, and you can override it. It's a net, not a plan.
> Values on screen are obvious fakes (API_KEY=xxxx-not-a-real-key). Transcript path label: ~/.claude/projects/. Push protection on by default for public repos since 2024-02-29. Mechanics of rotating and history rewriting belong to 08.07 and 15.11.

## 08 — Where the picture breaks
[[break]]Here's where the shop picture breaks. A real staff only sign is a rule people respect. A dot, or a Hidden flag, is only a display choice. [[walk-in]]Every program, every script, every agent, and every piece of malware walks straight in. There's no door, really. Just a tour that skips it. [[real-locks]]Real protection is something else: file permissions, encryption, a secrets manager. Those have lessons of their own.

## 10 — Then and now: from notes to orders
[[then]]In 2021, the back room held notes for tools: settings, history, a list of things to ignore. The worst common mistake was committing a dot E N V. [[now-orders]]Since 2025, some of those notes are orders. An agent follows them, and some are commands it runs. [[strangers-note]]So a stranger's note pinned to your wall gets obeyed too. In March 2025, researchers hid invisible instructions in a rules file. Others showed that a repository's own Claude settings could run commands or leak a key when someone opened it. Those holes were fixed, but the lesson stuck: these files are code. [[malware]]Malware learned the layout too. In August 2025, a poisoned package ran its victims' own AI command-line tools to search their disks for keys. [[leak-figure]]GitGuardian, a company that scans for leaked keys, counted AI-service keys leaking about eighty percent more in 2025 than the year before.
> All incidents are fixed; never imply they are open. Rules File Backdoor (March 2025) = Pillar Security research demonstration. Claude Code project-file flaws: CVE-2025-59536, CVE-2026-21852, published 2026-02-25, patched (CVE ids on screen at 26 px at most). Cursor MCPoison (approved mcp.json swapped silently, fixed in 1.3, 2025-07-29): optional small screen chip, not spoken. s1ngularity / Nx 2025-08-26, no victim counts. GitGuardian figure is a vendor figure: keep "GitGuardian · vendor figure" on screen. Depth is 15.15 and 05.08.

## 11 — Your job: check the back room
[[owner]]Your job is the owner's job. [[after-staff]]When an agent finishes, walk into the back room and look at what moved, hidden files included. [[diff]]Inside a project, git shows changes to dot files like any other file: git status lists them, and git diff shows the lines. Ignored files and your home back room don't show up there. [[review-as-code]]A change to a rules file or an M C P config deserves the same review as a change to code. [[polite-note]]A note asking the agent not to read your keys is a request, not a lock. Tools offer real deny rules and sandboxes, and some agents now refuse to rewrite their own settings files. [[heading]]One password manager, 1Password, is testing, in beta, a fake dot E N V that never touches the disk. The plain file is still the default.
> git status / git diff are named, not taught (08.02). Deny rules, sandboxes, protected paths: 14.12; protected paths are not on by default on native Windows, so make no claim that they protect a Windows user. 1Password Environments virtual .env: public beta since 2025-10-29, Mac and Linux. Do not predict the end of .env.

## 12 — The surprises you'll hit
[[no-git]]You'll open a project, see no dot git folder, and git works anyway. It's there, just hidden. [[windows-open]]On Windows, dot E N V and dot S S H sit right there in Explorer, while dot git doesn't. That's the flag, not the dot. [[still-on-github]]You'll add dot E N V to the ignore list, and it's still on GitHub. It was already committed. Replace the key. [[push-declined]]A push gets declined because it contains a secret. That's push protection. [[roaming-path]]A setup guide for a desktop AI app sends you to a path with App Data, Roaming in it. That's your home back room. [[ds-store]]On a Mac, files called dot D S Store turn up in projects and commits. Finder leaves them behind. [[leftovers]]And dot folders linger from tools you stopped using, like the one an AI tool you tried once left in your home folder.
> One card at a time. The push card uses a generic label "push declined: secret detected", not a quoted GitHub message (exact text unverified).
