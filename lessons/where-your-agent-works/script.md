## 08 — The speaking tube
[[tube]]The terminal is the workshop's speaking tube: just the window. [[shell]]The shell is the program at the other end, reading each line. Anthropic's terminal guide says Windows has two, PowerShell and C M D. [[ps]]PowerShell's prompt starts with P S; C M D's doesn't. A Mac uses Z shell. [[same-line]]One real line: echo first, double ampersand, echo second. C M D prints both. [[fails]]Windows PowerShell says the token double ampersand is not a valid statement separator. Same window, different shell, different meaning. [[as-you]]Whatever goes down the tube runs as you, with your permissions. What to check first is the lesson on letting it loose.
> Real capture shells (cmd, then Windows PowerShell 5.1; pwsh accepts &&). The && error is S206's wording (quickstart); prompts and Zsh are S207; "Any command you could run" is S101 (card).

## 10 — The house and the flat
[[build-rooms]]Sometimes the work gets a computer inside your computer. M I T's Missing Semester names two kinds. [[vm]]A virtual machine abstracts the entire computer, with its own operating system: a detached house on its own foundations. [[container]]A container packages an app with its files but shares the host's kernel: a flat in a shared building. Docker, the best-known container tool, was on Aaron's gap list. [[weaker]]M I T notes Docker's isolation is weaker than a virtual machine's. [[unattended]]Still, its exercises say an agent that skips approvals isn't secure run directly, but may be acceptable inside a virtual machine or container. That box is the lesson on sandboxes.
> S209 Packaging and Shipping Code (2026-01-20), Agentic Coding exercises (2026-01-21): "exercises", not "lecture". MIT's Docker line is about multi-tenant machines (card footnote): never "containers are unsafe". S210 (AO-029, 2026-10-01), no quote marks. Optional Blender shot house_and_flat at [[vm]].

## 11 — The spare workshop works on a copy
[[cloud-session]]A cloud session is the vendor's spare workshop: an isolated virtual machine Anthropic manages, still working after you close your laptop. [[copy]]Claude dash dash cloud clones your branch from GitHub, not the files on your bench, so push first. [[creds]]On Anthropic's hosting, your GitHub credentials never enter it. [[bundle]]With no GitHub remote, or no Claude GitHub App, your project is bundled and uploaded instead. Untracked files stay home; committed ones go up, keys included. On a Mac, Linux or W S L, uncommitted edits to files named like keys, such as dot E N V, stay too. [[windows-caveat]]On native Windows, uncommitted changes to tracked files upload whatever their name. Know what crosses.

## 12 — Desktop no longer means "on your computer"
[[processed]]First, on Pro and Max, desktop no longer means on your computer: Cowork's work, including local files it opens, is processed on Anthropic's servers. [[copies]]A task fetches a copy of just the file it needs; delete the session and those copies go too, under Anthropic's retention practices. [[keeps-going]]Close your laptop and Claude keeps going; scheduled tasks run with your computer off. [[hatch-narrow]]Second, the hatch: any connected folder is reachable, and on a computer your organization manages, those are your employer's files. [[one-folder]]So Anthropic advises one dedicated working folder; Ethan Mollick connects only a non-private part of his Google Drive. The folder lesson's habit, carried across town.

## 13 — Every landlord keeps a logbook
[[logbook]]And every landlord keeps a logbook. [[training]]First, training. Claude's Free, Pro and Max plans, Claude Code included, have a setting: Help improve our AI models. On, data can be kept up to five years; off, deleted chats are purged within thirty days. Pro is a consumer plan; Team, Enterprise and the A P I are commercial. [[already]]Switching it off doesn't reach training already started. [[memory]]Second, memory is a separate store. Delete a chat; its memories stay until you delete them too. [[accounts]]Third, keep work and home in separate accounts; shared logins aren't supported. [[other-landlords]]Others differ: Google has humans review some Gemini chats, and keeps reviewed ones up to three years, even after you delete your activity. [[four-questions]]Ask any tool four questions. Is there a training setting? Do people review chats? How long is data kept with it off? What does deleting reach? [[copies-stay]]The picture's last break: leaving a room doesn't take every copy with you.

## 14 — You and the agent
[[agent-part]]The agent decides whether a request needs a task, writes commands for its own shell, and fixes its own setup. Asked, it can usually fetch each vendor's privacy pages and answer the four questions, dated. [[your-part]]You choose the room, by the output; local or cloud; the account and its settings; one dedicated folder, never your home folder. [[approval]]And the approval level: current Claude Code starts in Auto, where a classifier blocks risky actions instead of asking you. Ethan Mollick's advice: until you trust the system, keep it asking. [[expert]]No agent can tell you whether your employer, a client contract or a privacy law lets that data go there. [[who]]So before work data goes in, ask your I T or security admin; for patient, client or customer data, whoever owns compliance.
> Currency (topic check): routing chat vs task, shell choice, setup fixes (/doctor) and SSH installs are now the agent's job (S102, S101, S208); taught here as the human's part: room, local/cloud, account, folder, approval level, expert sign-off. Auto: Claude Code v2.1.283+ and new desktop Code tab sessions (Cowork changelog 2026-09-24); Cowork scheduled tasks Claude creates use "Automatically approve" (2026-10-01). Modes themselves belong to the lesson on letting it loose. S249: "Until you trust the system ... ask for approval first". Expert card: IT/security admin on a managed computer (connected folders reachable from the cloud, S069); compliance, legal or data-protection owner for regulated data.
