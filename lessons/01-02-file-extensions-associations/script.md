## 01 — A label in the name, a ledger in the computer
In this lesson you'll learn how your computer decides which program opens a file, and how you change that decision. [[headline]] The extension is a label in the file's name, [[ledger]] your computer keeps a table that matches each label to a program, [[same-beads]] renaming changes the label but never the bytes, [[edit]] and Open with, set to always, and default apps are how you edit that table. [[agents]] AI tools now make files and pick their labels; the table still decides what opens them.

## 03 — The porter and the ledger
[[porter]] Now meet the porter. When you double-click a file, the porter takes the string. On Windows that's File Explorer; on a Mac, Finder. [[reads-tag]] The porter never looks at the beads. It reads only the tag, and only the part after the last dot. [[ledger-open]] Then it turns to a ledger on the desk, [[finger]] runs a finger down to the row for dot T X T, and reads the door written there: Notepad. [[carry]] It carries the string to that door and hands it over. The beads are never untied on the way. [[term]] That ledger has a proper name: file associations. [[per-user]] And there's one ledger per user account, so two people sharing a P C can get different programs for the same file.
> Speech says "ledger"; the screen adds the real term once: "file associations".

## 04 — What a ledger row holds
[[row-opens]] Look closer at one row, and it's more than a door. [[columns]] A row holds the program that opens the label, the icon stamped on every file wearing it, and the type's name you see in the folder, like Python file or Text document. [[menu]] It also holds the commands on that type's right-click menu. [[icon-flip]] That's why a renamed file's icon changes the instant you press Enter. Not one bead moved. The porter just reads a different row now. [[no-row]] And a label with no row at all gets a blank icon, and a question: which app should open this file?
> Columns from Microsoft's own list of what an association sets (program, icon, type name, shortcut-menu commands). No registry or ProgID words.

## 05 — The folded tag: hidden extensions
[[folded]] Windows and Mac still hide most extensions by default, and neither has announced a change. The tag is folded at the last dot, so you only see the front. [[fold-trap]] A file really named hello dot P Y dot T X T shows up as hello dot P Y. It's still a text file. You can't fix a label you can't see. [[unfold]] Showing extensions is one setting on each system. [[advanced]] On recent Windows, it sits on a settings page Windows now calls Advanced. [[mac-per-file]] A Mac can also hide the extension per file, so two files in one folder can disagree. [[builders]] People who build things nearly always switch extensions on.
> Screen labels only: "Show file extensions", "Advanced (formerly For developers) · Windows 11 25H2+", "Hide extension" (Mac, per file). Card: "Windows 11 26H2 · macOS 27 · still hidden by default · Oct 2026". No click path spoken or drawn as a trail.

## 06 — Renaming: a new tag, the same beads
[[rewrite]] Renaming rewrites the tag. The beads stay put. Microsoft says it plainly: renaming won't convert the file. [[aaron-payoff]] That's why Aaron's fix worked. His beads were already Python text; the dot T X T tag was just sending them to the wrong door. [[png-jpg]] But rename photo dot P N G to dot J P G and nothing converts. It may still open, because photo apps read the beads, but it's still a P N G. [[export]] Real conversion happens inside an app, with Save As or Export. [[warning]] The warning you get when you change an extension is the porter saying: you're moving rows. [[classic-trap]] And the classic trap: with extensions hidden, or Notepad saving as a text document, typing hello dot P Y as the name can end up as hello dot P Y dot T X T. It looks right. It isn't.
> Warning cards are paraphrased, not mock dialogs: Windows "might become unusable"; Mac "Keep .txt / Use .py". "can end up", never "always". Not Aaron's story.

## 07 — Open with: just once, or always
[[note]] Open with is you telling the porter which door, for this one file. [[once]] There are two kinds of answer. A one-time choice opens the file in that program and leaves the ledger alone. [[always]] An always choice picks up the pen and rewrites the row, so every file with that label goes there from now on. [[mac-change-all]] On a Mac, picking a different app in a file's info window changes only that one file, unless you press Change All. [[per-file]] So a Mac can remember a choice per file. Windows remembers per label.
> Generic "Just once" / "Always" pills, not a screenshot-like dialog (the exact Windows dialog varies by machine). "Change All" on screen.

## 08 — Default apps: the whole ledger
[[book]] Default apps, in Windows Settings, is the ledger itself, opened like a book. A default app is just the program a row points to. [[by-label]] You can look it up by label, one row at a time. [[by-app]] Or look it up by app: pick a browser, and see every label it can open, and who holds each row now. [[proof]] Here's proof the ledger works label by label. When Windows eleven launched in twenty twenty-one, switching your browser meant changing each label one by one. [[one-click]] A one-click Set default button came back the next spring. [[europe]] In Europe, since last year, that button rewrites many more rows at once. Same ledger, a bigger pen.
> Cards: "Windows 11 launch · Oct 2021", "Set default returns · Mar 2022", "EEA only · Jul 2025". Never worldwide for the EU change.

## 09 — Who gets to write in the ledger
[[hands]] You're not the only one holding a pen. [[installer]] Installers write rows: install a code editor, or Python, and it can claim dot P Y. [[update]] Updates write rows too. A twenty twenty-three update taught Windows to open seven Z and RAR archives itself. [[ask-rule]] Since twenty twenty-three, Microsoft's rule is that apps should send you to Settings to ask, not quietly take the row. [[glass]] Since twenty twenty-four, Windows guards some rows, like web links and P D Fs, so only you can change them. And since last year, it records your choice in a new, locked form. [[side-effect]] One side effect: sometimes, after an upgrade, a new default doesn't stick until you reset your defaults. [[grab]] And people still report apps grabbing file types.
> Cards: "Microsoft's principles · Mar 2023", "Windows 11 23H2 · Oct 2023", "guarded rows · 2024", "locked record · 2025". No driver, registry, hash or app names. "should", not "can't".

## 10 — Where the picture breaks
[[three-ledgers]] Here's where the picture breaks: there isn't one ledger. Windows keeps its table in the registry. A Mac maps the label to a type, then the type to an app, and keeps per-file choices. Linux desktops also peek at the contents, and keep your choices in a plain text file. [[front-door]] And the porter only works the front door: double-click, Open with, the system's own open command. [[walk-past]] Name the program yourself, python notes dot T X T, and no ledger is consulted. [[two-pythons]] So double-clicking script dot P Y and typing python script dot P Y can run different Pythons. The double-click runs whichever Python the ledger points at, not the one in your project's dot V E N V. [[web]] And on the web, the server's label decides, not the extension.
> Nouns on screen only: "registry", "label → type → app", "peeks at contents · a text file". `.venv` named only (05.03); Content-Type named only (09.06).

## 11 — A second ledger inside your editor
[[inner-ledger]] Programs keep private ledgers too. [[vscode]] V S Code reads the extension to pick its colours and checks, which it calls the language mode, and you can remap it. [[two-tables]] So hello dot P Y dot T X T opens in Notepad, and gets no Python colours in V S Code either. Two ledgers, one label. [[guess]] With no label at all, it guesses from the content. [[ai-labels]] Around AI, labels are promises about how to load a file. Older model files, like dot C K P T, could run code when loaded; dot safe tensors was made so they can't. Dot G G U F marks a local model. And M C P bundles are zips wearing their own label, like a Word file. [[no-disguise]] Renaming one to dot safe tensors doesn't make it safe. It just won't load.
> Screen: `.safetensors` vs `.ckpt` / `.pt`, `.gguf`, `.mcpb` (zip + manifest). Depth lives in 01.10, 10.09, 15.17.

## 12 — The surprises you'll hit
[[flash]] Double-click a dot P Y file, and what happens depends on the machine. Often it runs, and the window closes before you can read it. It ran; it didn't open for editing. [[how-open]] A box asking which app to open it with means the label has no row. [[no-ext]] A file with no extension at all gets a blank icon and the same question. [[doesnt-stick]] Sometimes a default won't stick after an upgrade. That's a side effect of the locked record from earlier, and resetting your defaults usually fixes it. [[wont-open]] The icon changed after a rename, but the file won't open? The new door can't read those beads. [[costume]] And invoice dot P D F dot E X E is the folded tag's other face: a program in a costume. The Trust district covers that one.
> No scare tone. invoice.pdf.exe owned by 15.17; one line only. "Depends on the machine": never show one outcome as universal.

## 13 — The lantern: AI makes the file, the ledger still opens it
[[five-years]] Five years ago, you created and named every file yourself, and AI was autocomplete inside it. [[assistants]] Since twenty twenty-three, and everywhere by now, assistants like Claude and ChatGPT hand you real Word, Excel, PowerPoint and P D F files, and coding agents write project files with labels they choose. [[show-run]] When an agent shows you a file, it usually asks the same porter. When it runs code, it names the program and walks past the ledger. [[ai-actions]] Windows has started adding AI actions to the right-click menu, and which ones you get depends on the label: image tools only for J P G and P N G. [[connector]] Windows is also previewing a way for agents to reach files, only in folders you allow; it still reports the extension separately. [[mac-names]] Mac OS twenty-seven now suggests file names from what's inside, but the label still picks the app. [[heading]] The direction looks like more rows only you can change, and more doors for agents that need your permission.
> Cards: "AI assistants make real files · 2023 → 2025", "AI actions · rolling out since Oct 2025 · .jpg .jpeg .png · varies by market", "File Explorer agent connector · preview", "macOS 27 · Sept 2026". "usually", "previewing", "the direction looks like" mark the hedges.
